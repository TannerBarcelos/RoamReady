# Camping icon assets

All 32 assets are single-scale, preserved vectors with template rendering. Use `Image("AssetName")` with template rendering and the desired tint. `RigGlyph` handles Dynamic Type and the asset mapping for the eight current rig types. `RigRooftopTent` is available for future UI without changing the rig model.

Lucide assets are copied from the upstream SVGs, with `currentColor` changed to black for template rendering. The full upstream license ships in `Camp/Resources/Lucide-LICENSE.txt`. Original artwork uses the project's license. All artwork uses a 24 × 24 view box with rounded 2-point strokes.
